## [1.0.0] - TBD

### Added
- Interactive TUI with three-panel layout (Query, Input, Output)
- Real-time query execution with 5-second timeout protection
- Support for both jq and yq engines
- AI query generation using OpenAI GPT-4o-mini
- Context-aware AI prompts with current data
- File picker for loading input files and saving output
- Keyboard navigation with Tab cycling
- Responsive layout that adapts to terminal resizing
- Environment variable configuration (OPENAI_API_KEY)
- Command-line argument support (--input, --yq, --jq)
- Cross-platform releases (Linux, macOS, Windows)
- Installation script for easy setup
- Comprehensive documentation and examples
